# План оптимизации производительности RAG-чата

## Проблема
Запрос обрабатывается более 30 минут из-за множественных последовательных вызовов:
1. **LLM rewriting** (1 вызов к LocalAI)
2. **Multi-query generation** (1 вызов к LocalAI)
3. **FAISS search** по каждому переписанному запросу
4. **Cross-Encoder reranking** (медленный инференс на CPU/GPU)
5. **LLM-as-a-Judge** (2 вызова к LocalAI — faithfulness + relevancy)

**Итого: 4+ вызова LLM + 1 тяжелый cross-encoder на каждый пользовательский запрос.**

## Решение

### 1. Отключить LLM-as-a-Judge по умолчанию (USE_JUDGE = False)
- Judge добавляет 2 лишних вызова LLM после каждого ответа
- Пользователь получает answer + extra latency для метрик
- **Результат: экономия ~2L вызовов на запрос**

### 2. Отключить Multi-Query (USE_MULTI_QUERY = False)
- Multi-query генерирует 3 запроса через LLM, затем делает 3 поиска в FAISS, затем RRF-слияние
- Для быстрого ответа это избыточно
- **Результат: экономия 1 LLM-вызов + 2 лишних поиска**

### 3. Отключить Query Rewriting (USE_QUERY_REWRITING = False)
- Переписывание вопроса через LLM добавляет задержку
- Для простого документа search на оригинальном вопросе работает хорошо
- **Результат: экономия 1 LLM-вызов**

### 4. Отключить Reranking (USE_RERANKING = False)
- Cross-encoder на CPU/GPU — самая медленная операция (~5-30 сек)
- FAISS с k=4 уже даёт достаточное качество для короткого документа
- **Результат: экономия ~5-30 секунд на каждый запрос**

### 5. Сократить TOP_K_BASE (20 → 5)
- Для 1-страничного документа 20 чанков избыточно
- **Результат: меньше поиска, меньше данных**

## Итоговые флаги

```python
USE_QUERY_REWRITING = False    # убрали LLM-препроцессинг
USE_HYDE = False               # не используем
USE_MULTI_QUERY = False        # убрали множественные запросы
USE_RERANKING = False          # убрали cross-encoder
USE_JUDGE = False              # убрали judge-цепочку
TOP_K_BASE = 5                 # меньше чанков
TOP_K_FINAL = 4                # мало для генерации
```

## Ожидаемый результат
- **Было:** 4+ LLM-вызовов + cross-encoder = **30+ минут**
- **Стало:** 1 LLM-вызов (генерация ответа) = **3-10 секунд**
