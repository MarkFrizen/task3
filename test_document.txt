Название компании: ООО «Интеллектуальные Системы»

Основные направления деятельности:
- Разработка AI-решений для бизнеса.
- Создание чат-ботов на базе RAG (Retrieval-Augmented Generation).
- Консалтинг по внедрению LLM.

Ключевые продукты:
1. RAG-платформа «Знание» – позволяет строить корпоративные базы знаний с доступом через естественный язык.
2. Ассистент «Умник» – чат-бот для внутренней поддержки сотрудников.
3. Аналитическая панель «Инсайт» – визуализация данных с элементами прогнозирования.

История компании:
ООО «Интеллектуальные Системы» основано в 2020 году. За 4 года команда выросла с 5 до 50 сотрудников. Клиенты: более 200 компаний из финансового, ритейл и производственного секторов.

Технологический стек:
- Python (FastAPI, LangChain, PyTorch)
- Векторные БД: FAISS, Qdrant, Pinecone
- Модели: открытые (Llama, Mistral, Qwen) и проприетарные (OpenAI, Anthropic)

Планы на 2026 год:
- Запуск международной версии платформы.
- Интеграция с мультимодальными моделями.
- Увеличение штата до 80 человек.
